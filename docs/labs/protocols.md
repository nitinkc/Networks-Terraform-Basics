

Protocol,What it does in 1 sentence,When to learn it
**ARP**,Maps an **IP address to a MAC address** so the switch can deliver the frame.,**Right now** (before adding more routers)
**DHCP**,"Automatically hands out IP, Subnet Mask, and Gateway to hosts so you don't type them manually.",**Next** (in this lab)
**DNS**,Translates domain names (my-server.com) into IP addresses (198.51.100.2).,**After DHCP**
**NAT / PAT**,Swaps private IPs (192.168.x.x) for a public IP (203.0.113.1) so internal devices can talk to the WAN.,**In this lab**
**BGP / OSPF**,Dynamic routing protocols where routers talk to each other to share routes automatically.,**Much later** (skip BGP for now — it is used for internet service providers)
